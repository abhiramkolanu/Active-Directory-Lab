# Active-Directory-Lab
<h2>About this Project</h2>
In this project I created an Active Directory in my own virtual environment. I utilized VMware Workstation Pro as my virtualization software and downloaded Windows Server 2019 and Windows 10 OS from the official Microsoft website to serve as software for my virtual machines. This project taught me how Active Directory is utilized in enterprise IT environments and how important it is to company security to manage all users in a network in one consolidated location. Additionally this project also taught me about networking fundamentals. To simulate a secure enterprise environment, I needed to configure a functioning LAN network that also allows devices on the internal network to access the external internet securely. In order to do this I needed to enable routing within the Domain Controller and configure the DHCP to assign IP addresses, provide a default gateway, and provide a DNS to client virtual machines. Overall, this project taught me about basic IT software that is utilized in almost every IT workplace and I feel like these project made me more prepared to work in the IT space.
